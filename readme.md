# OpenPivot

**OpenPivot** is the result of my effort at **reverse-engineering** the **Pivot Animator file format (`.piv`)**.

> [!WARNING]
> The code is still **experimental** and **errors should be expected** when running this program.

This project is currently divided in **different parts**:
- `Unai.OpenPivot`: the **base class library (BCL)** for all operations related to `.piv` files.
- `Unai.OpenPivot.Cli`: a basic **command line interface (CLI)**, mainly for debugging purposes.
- `Unai.OpenPivot.Gui.Uno`: a **graphical user interface (GUI)** powered by the **Uno Platform** used to better visualize the parsed `.piv` files.

## Disclaimer

OpenPivot is not affiliated with Pivot Animator.
